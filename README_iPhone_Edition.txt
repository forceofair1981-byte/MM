Muscle Atlas Pro 3.8.2 — Activity Ring Split (iPhone Edition)

新仕様：アクティビティリングは「ウエイトトレーニング」「有酸素運動」「食事」の3本。
・ウエイト：過去7日間にウエイト種目（exercises）が記録された日数（1日1カウント）
・有酸素：過去7日間に有酸素運動（cardio）が記録された日数（1日1カウント）
・食事：過去7日間に食事が記録された日数（1日1カウント）
・同じ日にウエイトと有酸素の両方がある場合、それぞれ1日として数えます。
・体調リングのみ削除。血圧・心拍数の機能や既存保存データは変更しません。
・達成率は7日間の記録日数を表し、活動強度・カロリー・目標達成率とは異なります。

GitHub Pages: ZIPを解凍して、すべてのファイルを同じリポジトリのルートに上書きアップロードしてください。
更新前に設定画面でJSONバックアップを取得してください。
サイトデータ・キャッシュ・IndexedDBを手動削除しないでください。

3.8.2: 五つの筋群（胸・肩・腹筋・背筋・脚）の回復期間を自動/1〜14日で個別指定可能。ヒートマップのSVG画像配色がライト/ダークに連動。

3.8.4 — 食品パッケージ写真の補助入力を削除（食品手入力・食品解析・PFC管理は維持）。血圧計・心拍計の写真は維持。
3.8.4 — トレーニング履歴と食事履歴に過去3年/1年フィルターと45日ずつの追加表示を導入。3年以前の履歴も保持。食事の30,000件での暗黙の切り詰めを廃止。
注意: Safari/ホーム画面Webアプリの端末内IndexedDBに保存します。3年以上の記録にも対応しますが、ブラウザーやiPhoneの保存領域消去、容量不足、機種変更ではデータが失われる場合があります。最低月1回のJSONバックアップを推奨します。既存データの自動削除はありません。

3.8.5 — 種目辞書から種目を選ぶと解析結果のカードに直接追加。重量・回数・セット数・RIRを編集可能。文章入力との併用や再解析にも対応。

3.8.6 — 種目リストを「部位 → 器具・方法（中分類） → 種目」の3段階で選択可能に変更。

3.8.7 — トレーニング記録画面は日付などの基本情報の下に「カタログ入力」を先に表示し、次に「文字入力（自由記述）」を配置。カタログは初期展開。既存の解析・編集・記録機能は変更しません。
