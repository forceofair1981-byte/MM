Muscle Atlas Pro v3.8.0 — iPhone Edition
========================================

GitHub Pagesでの更新
1. 旧アプリで「設定・データ」→「JSONバックアップ」を書き出してください。
2. ZIPを解凍し、すべてのファイルをGitHubリポジトリのルートへアップロードしてください。
   ※ 特に ios-fitness.css を含め、同梱されたファイルを省略しないでください。
3. GitHub Pagesの公開後、iPhoneのSafariで同じURLを再読み込みしてください。
4. 表示が古い場合は再読み込みします。閲覧データの一括削除はしないでください。

今回のUI変更
- Appleのフィットネス/ヘルスケアアプリを参考にしたiPhone向けカード型ホーム画面。
- アクティビティリングは「直近7日間の筋トレ・食事・体調の記録日数÷7」の割合。
  達成目標や医療上の状態を表示するものではありません。
- 曜日別の棒グラフは直近7日間に保存したトレーニングセッション数。
- ライトモード、ダークモード、OS設定連動を維持。
- 主要な7画面、各種記録、分析、6言語および端末内保存方式を維持。

注意
- トレーニング・食事・体調などのデータは元の端末内ストレージに保存されます。
- URLのオリジンを変更すると元の保存データは自動では移動しません。
- 計算処理に手を加えず、UI表示とその集計表示だけを追加しています。
- 端末Safariの全操作はこの環境では確認できていません。
